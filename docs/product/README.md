# docs/product/

What DancePatternMapper does for the user, one living spec per feature area. The format and rules
are in [`docs/README.md`](../README.md).

The specs are being written from the app as it is (PRs after the one that added this folder).
Until a file exists, the nearest descriptions are the README's _Features_ section and the
`AGENTS.md` file for that area.

| File (planned)          | Area                                                                         |
| ----------------------- | ---------------------------------------------------------------------------- |
| `overview.md`           | Every feature area in a line, with links                                     |
| `lists-and-figures.md`  | Lists, figures, types, levels, tags, modifiers, rhythm, templates            |
| `map.md`                | Timeline and network views, filtering, dragging, editing from the Map        |
| `reels.md`              | The Reels tab                                                                |
| `sharing.md`            | Publish, subscribe, members-only lists, handover, suggestions, reports       |
| `video-tools.md`        | Shorten, anonymize, transcribe, suggest a name and description, put online   |
| `settings.md`           | Styles, app icon, languages, on-device models, import and export             |
| `glossary.md`           | Dance terms and the app's own words                                          |
