# 0009: Export files are for backups and moving phones, not for sharing

- **Status:** accepted
- **Date:** 2026-10-25
- **Decided by:** Oliver
- **PR:** #113
- **Recorded from:** Project memory (website review 2026-10-25)

## Context

The website and README presented export and import as a way to share lists. That competes with
publishing, which keeps lists in sync and in the owner's control.

## Decision

Export and import are presented only for backups and for moving to a new phone. Sharing with
others is publishing a list.

## Alternatives considered

- **Keep files as a second way to share**: Oliver called them a crutch for that.

## Consequences

- App text, website and docs describe export that way.
- An editable export still hands over control of a published list, on purpose
  ([0002](0002-anonymous-sign-in-and-owner-records.md)).
