# 0010: A variation of a figure is a modifier on it, not a new figure

- **Status:** accepted
- **Date:** 2026-10-03
- **Decided by:** Oliver
- **Recorded from:** Project memory (WCS terminology, 2026-10-03)

## Context

Early website drafts listed variations as separate figures ("Inside Turn Whip" beside "Basic
Whip"). Oliver corrected them: a turn added to a figure is a modifier of it.

## Decision

- Variations are modifiers ("with Inside Turn"), attached to the base figure. Each attachment can
  carry its own videos.
- Modifiers that fit any figure (Hesitation, with Hand Change) can be universal.
- Example and template content uses only real, verified figure names.

## Alternatives considered

- **Variations as figures of their own**: what the drafts did, and what Oliver ruled out.

## Consequences

- Counts and rhythm per variant go only on attached modifiers (Oliver, 2026-10-31).
- See `docs/product/glossary.md` for the term rules.
